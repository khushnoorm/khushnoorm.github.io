संख्या पद्धति

Numbers को पहचानना, वर्गीकृत करना और उनके गुण समझना सीखें।

अध्याय टेस्ट
इस पाठ मेंप्राकृतिक और पूर्णपरिमेय संख्याएँअपरिमेय संख्याएँवास्तविक संख्याएँघातांक के नियमअभ्याससारांश

1. प्राकृतिक, पूर्ण और पूर्णांक

परिभाषा

प्राकृतिक संख्याएँ (N) गिनती की संख्याएँ हैं: 1, 2, 3, …। शून्य जोड़ने पर पूर्ण संख्याएँ (W): 0, 1, 2, … मिलती हैं।

धनात्मक संख्याएँ, शून्य और ऋणात्मक संख्याएँ मिलकर पूर्णांक (Z) बनाती हैं।

Z = { …, −3, −2, −1, 0, 1, 2, 3, … }
उदाहरण

−5 एक पूर्णांक है, लेकिन प्राकृतिक संख्या नहीं। 0 पूर्ण संख्या और पूर्णांक है। इस पाठ में प्राकृतिक संख्याओं की शुरुआत 1 से मानी गई है।

2. परिमेय संख्याएँ (Rational Numbers)

जिस संख्या को p/q के रूप में लिखा जा सके, जहाँ p और q पूर्णांक हों और q ≠ 0, वह परिमेय संख्या है।

Q = { p/q : p, q ∈ Z और q ≠ 0 }

इनका दशमलव प्रसार या तो समाप्त होता है, जैसे 1/2 = 0.5, या आवर्ती होता है, जैसे 1/3 = 0.333…।

3. अपरिमेय संख्याएँ

जिन वास्तविक संख्याओं को p/q के रूप में नहीं लिखा जा सकता, वे अपरिमेय हैं। इनका दशमलव प्रसार अनंत और अनावर्ती होता है।

उदाहरण

√2, √3, π और e अपरिमेय संख्याएँ हैं। ध्यान दें: हर वर्गमूल अपरिमेय नहीं होता; √4 = 2 परिमेय है।

4. वास्तविक संख्याएँ

परिमेय और अपरिमेय संख्याओं का संयुक्त समुच्चय वास्तविक संख्याएँ (R) कहलाता है। संख्या रेखा का हर बिंदु किसी वास्तविक संख्या को दिखाता है।

R = Q ∪ (अपरिमेय संख्याएँ)
संख्या परिवार

N ⊂ W ⊂ Z ⊂ Q ⊂ R

5. घातांक के महत्वपूर्ण नियम

a ≠ 0 और उचित वास्तविक मानों के लिए:

aᵐ × aⁿ = aᵐ⁺ⁿ   |   aᵐ ÷ aⁿ = aᵐ⁻ⁿ
(aᵐ)ⁿ = aᵐⁿ   |   a⁰ = 1   |   a⁻ᵐ = 1/aᵐ
हल किया उदाहरण

2³ × 2⁴ = 2³⁺⁴ = 2⁷ = 128

7. सारांश

  • ✓ प्राकृतिक ⊂ पूर्ण ⊂ पूर्णांक ⊂ परिमेय ⊂ वास्तविक
  • ✓ परिमेय दशमलव समाप्त या आवर्ती होते हैं।
  • ✓ अपरिमेय दशमलव अनंत और अनावर्ती होते हैं।
  • ✓ हर परिमेय और अपरिमेय संख्या वास्तविक है।
